# Security policy

Please report suspected security vulnerabilities privately to [info@amara.gmbh](mailto:info@amara.gmbh). Do not open a public issue for a vulnerability that has not been resolved.

Include the affected version, platform, steps to reproduce, and the potential impact. Please avoid sending passwords, private recordings or other sensitive material; use a minimal example where possible.

We will review reports and coordinate disclosure with the reporter. Security fixes are intended for the latest release; older versions may not receive updates.
